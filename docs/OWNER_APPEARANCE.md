# Owner-created appearance collection

Owner explicitly confirms all wallpapers and dice/application icons were personally generated using AI, mostly Gemini/ChatGPT, and authorizes their distribution in the DnD-VTT workshop. No CC0 or third-party reuse license is asserted. Author: waitermisanthrope-creator. Per-file generator attribution is not invented.

63 source images: 32 wallpapers (including 2 SVGs), 30 dice-icon images and the original standard launcher preview 1790788500741.png. Source path/SHA pinned in migration/owner-appearance.json to application source d4f62bde. PNG payloads preserve decoded source pixels; SVGs are rasterized for Unity support with external/active SVG content rejected. Original application files remain unchanged.

Each image is an independent JSON package <=5 MiB, hosted in immutable GitHub Release owner-appearance-v1 rather than ordinary Git history. New catalog v3 is activated only after downloading/verifying public package sizes and SHA-256. v2 stays unchanged for old clients. The native client can apply wallpapers and view/export icon PNGs; Android system launcher-icon switching is not implemented by downloadable files.
