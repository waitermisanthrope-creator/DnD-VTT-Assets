# DnD-VTT-Assets
3D models, textures, animations and downloadable Unity asset packs for DnD-VTT


## Asset storage foundation

- [`catalog/v1/index.json`](catalog/v1/index.json): approved asset-pack catalog (currently empty).
- [`schemas/asset-pack-v1.schema.json`](schemas/asset-pack-v1.schema.json): platform-aware Android/Windows manifest schema.
- [`docs/ASSET_PIPELINE.md`](docs/ASSET_PIPELINE.md): proposed review, build, verification and release pipeline.

Heavy binaries belong in versioned Releases, not Git history. Unity bundle installation is not implemented yet.
